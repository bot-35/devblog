### View Transitions API

L'un des avantages comparatif des applications SPA sur les MPA est qu'on peut ajouter un **effet de transition** à la modification du DOM.

Cela permet pendant le chargement des données, de **garder l'attention** de l'utilisateur sur l'application en plus d'embellir son expérience.

Cependant, la création de transitions de vues sur le Web a toujours été **difficile**, impliquant d'**importantes** écritures de CSS et JavaScript.

Mais depuis le **Mars 2023** une API nommée <a href='https://developer.mozilla.org/en-US/docs/Web/API/View_Transitions_API#the_view_transition_process*'>View Transitions API</a> entièrement supporté par Chronium est venue changer la donne.

L'API View Transitions fournit une manière plus **simple** de gérer les animations de transition et les modifications du DOM.

Je vous invites à lire la <a href='https://developer.mozilla.org/en-US/docs/Web/API/View_Transitions_API'>documentation</a> pour mieux vous familiariser avec cette API mais voici un résumé de son fonctionnement :

- Quand le navigateur reçoit une demande de changement de page, l'API prend une **capture d'écran** de la page actuelle.
- Le DOM ce **met à jour**.
- L'API prend une **capture d'écran** de la nouvelle page.
- L'API anime la première capture pour aller vers l'état de la deuxième capture avec par défaut un **effet d'opacity** où bien avec les **animations définis** dans le CSS.
