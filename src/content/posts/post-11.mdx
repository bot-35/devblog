## Introduction


J'étais en train de travailler sur mon prochain article (comment héberger bitwarden en local) quand j'ai eu besoin de **retrouver les versions de .NET SDK** installées sur ma machine afin de répondre à un prérequis bien précis (NET 6.0 SDK).

La procédure se trouve assez facilement, mais j'ai quand même eu envie de la **garder en mémoire** sur ce blog. 👀

## DotNetVersionLister

<a href='https://github.com/EliteLoser/DotNetVersionLister/tree/master/5AndUp'>DotNetVersionLister2</a> comme son nom l'indique vous fournit les outils pour **lister les versions** présentes sur votre machine.

### Installation

Entrez cette **commande** dans votre terminal.

<CodeBox code={`
Invoke-WebRequest -OutFile Get-STDotNetVersion2.psm1 -Uri 'https://raw.githubusercontent.com/EliteLoser/DotNetVersionLister/master/5AndUp/Get-STDotNetVersion2.ps1'

Import-Module -Name ./Get-STDotNetVersion2.psm1    
`} lang="ps1" theme="vitesse-dark" header="Terminal"/>

Et voilà c'est **installé**.

### Utilisation 

La commande d'utilisation de cet outil est : <LittleCode code='Get-STDotNetVersion2' lang="ps1" theme="vitesse-dark"/>.

Ce qui donne comme résultat dans mon cas.

<CodeBox code={`
PS E:\\admin> Get-STDotNetVersion2

ComputerName   : PC-MAX
SDKVersion     : 6.0.413
SDKPath        : C:\\Program Files\\dotnet\\sdk
RuntimeType    :
RuntimeVersion :
RuntimePath    :

ComputerName   : PC-MAX
SDKVersion     : 7.0.402
SDKPath        : C:\\Program Files\\dotnet\\sdk
RuntimeType    :
RuntimeVersion :
RuntimePath    :
`} lang="powershell" theme="vitesse-dark" header="Terminal"/>


    
Manifestement mon poste **répond** aux prérequis de bitwarden, avec la version .NET 6.0 et <a href='https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/sdk-7.0.402-windows-x64-installer'>.NET 7.0</a>.

## Conclusion

Grâce à DotNetVersionLister2 j'ai pu **m'assurer** que ma machine disposes bien des prérequis nécessaires pour faire fonctionner localement bitwarden sur ma machine.

**Faites attention** il existe une version précédente nommée <LittleCode code='Get-STDotNetVersion' lang="ps1" theme="vitesse-dark"/>. Cette version **ne peut pas** rechercher les versions de .NET supérieur ou égale à .NET 5.0. 

C'est tout pour aujourd'hui. 🐱‍💻
