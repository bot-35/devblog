## npm 

npm est un manageur de paquet très populaire auprès des développeurs Node.js et Javascript.

Crée en 2009, ce projet open source avait pour but de faciliter le partage et la distribution de modules (paquet) dans la communautée Node.js.

Aujourd'hui, npm est devenu un outil central dans l'écosysteme JavaScript en devenant même le plus grand registre logiciel du monde. 

Si vous avez déjà installé Node.js alors vous avez déjà npm sur votre machine 🎉.

Vous en doutez ? Alors un petit  <LittleCode code='npm help' lang="sh" theme="vitesse-dark"/> dans votre terminal devrait vous en assurait.

On l'utilise particulièrement pour :

- **Initialiser** un projet JavaScript avec  <LittleCode code='npm init' lang="bash" theme="vitesse-dark"/>.<br/> 
A partir d'une série de question, npm produit un fichier  <LittleCode code='package.json' lang="bash" theme="vitesse-dark"/> pour votre projet.
- **La gestion des dépendances** avec  <LittleCode code='npm install nom_du_paquet' lang="bash" theme="vitesse-dark"/> vous pouvez ajouter des dépendances à votre projet.<br/> 
Il existe aussi une gestion de versioning des paquets vous permettant de choisir la version du que vous voulez installer.<br/> 
<LittleCode code='npm install nom_du_paquet@latest' lang="bash" theme="vitesse-dark"/> installera la dernière version alors que <LittleCode code='npm install nom_du_paquet@2.85' lang="bash" theme="vitesse-dark"/> installera la version... 2.85 😎.
- **Utiliser des scripts**  avec <LittleCode code='npm run nom_du_script' lang="bash" theme="vitesse-dark"/>. 
Dans <LittleCode code='package.json' lang="bash" theme="vitesse-dark"/> vous trouverez une section script vous permettant d'ajouter et modifier des scripts.<br/>
Exemple : <LittleCode code='"dev": "astro dev"' lang="json" theme="vitesse-dark"/> permet de lancer le serveur de développement d'Astro avec la commande <LittleCode code='npm run dev' lang="bash" theme="vitesse-dark"/> .
 
## npx

npx est un outil en ligne de commande introduit avec la version 5.2.0 de npm. Il répond au besoin d'exécuter des paquets et binaires en CLI sans avoir à les installer en globale. Un exemple fameux est React. <br/>
Au départ nous l'installions de cette manière : <LittleCode code='npm install -g create-react-app' lang="bash" theme="vitesse-dark"/>, alors qu'aujourd'hui on utilisera plutôt <LittleCode code='npx create-react-app my-app' lang="bash" theme="vitesse-dark"/>
