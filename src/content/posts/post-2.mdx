    ## Le futur est déjà là !
    Personne n'est passé à côté de la **folle** arrivée de **ChatGPT** et des débats sur les **IA** qui en on découlés ! 
    
    Pour les plus pessimistes, c'est l'inexorable mort programmé du <a href='https://www.radiofrance.fr/franceinter/chez-onclusive-plus-de-la-moitie-des-salaries-francais-remplaces-par-des-outils-d-intelligence-artificielle-4134887'>travail humain</a>, voir de la race toute entière.

    Pour les plus optimistes au contraire, l'IA nous permettra et nous permet déjà de faire d'énormes avancé en matière de santé, d'agriculture et autre exploration spatiale.

    Nous, on va rester un peu plus terre-à-terre si vous le voulez bien et jouer avec un **IDE** (Environnement de Développement Intégré) qui embarque **deux versions de ChatGPT**.

    Cette IDE, c'est <a href='https://cursor.so/'>Cursor</a> développé par <a href="https://anysphere.co/">Anysphere</a>.


    ## De solides fondations

    Bonne nouvelle !  Si vous êtes un utilisateur de **Visual Studio Code**, vous ne devriez pas être dépaysé.

    En effet, Cursor est basé sur <a href='https://vscodium.com/'>VSCodium (les binaires de VS Code)</a> ce qui signifie qu'en plus d'être très proche niveau interface de VS Code, Cursor utilise le **même marketplace** que celui-ci vous permettant de retrouver vos extensions favorites.

    A l'heure où j'écris ces lignes, le code de Cursor n'est pas open-source. Cependant, Anysphere n'exclue pas de rendre tout ou partie de son code ouvert à l'avenir tel qu'indiqué sur leur <a href='https://github.com/getcursor/cursor'>dépôt git</a>.

    ## Bonjour Cursor

    Cursor embarque avec lui **deux versions** de ChatGPT.

    - GPT-3.5 
    - GPT-4
    
    Pour ce qui est du modèle économique, Anysphere vous offre **50 prompts GPT-4** à l'ouverture de votre compte.

    Une fois cette limite dépassée, vous aurez encore mensuellement droit à **200 prompts** gratuits en GPT-3.5.

    Voilà qui devrait nous permettre de nous amuser un moment avant de devoir passer à la caisse !

    ## Cursor et l'IA
    

    Grace à l'IA de Cursor, vous pourrez :
    - Lui demander de **démarrer** un projet avec du code de base
    - Obtenir des **suggestions** de code
    - Lui faire **déboguer** votre code
    - Lui demander des **explications** sur des concepts de programmation
    - Lui faire **analyser** votre code
    - Lui demander **d'écrire** des rédactions.



   >Cette combinaison de l'IDE et de l'IA vous permet d'explorer de nouvelles possibilités et d'améliorer votre productivité en tant que développeur.<br/> <br/> 
   >Vous pouvez utiliser les fonctionnalités de l'IDE pour écrire du code, tandis que les modèles de ChatGPT peuvent vous aider à générer du code, à répondre à des questions ou à résoudre des problèmes.<br/> <br/> 
   >Par exemple, vous pouvez utiliser ChatGPT pour obtenir des suggestions de code, pour expliquer des concepts de programmation ou pour obtenir de l'aide sur des erreurs spécifiques. L'IA peut également vous aider à automatiser certaines tâches répétitives ou à générer du code de base pour vous faire gagner du temps.<br/> <br/> 
    >Avec Cursor, vous avez accès à un environnement de développement puissant et à une IA avancée pour vous accompagner dans vos projets de développement. Que vous soyez un développeur expérimenté ou débutant, Cursor peut vous aider à améliorer votre flux de travail et à développer des applications plus rapidement et plus efficacement.
