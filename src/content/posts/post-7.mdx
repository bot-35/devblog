## Homepage : Beau, rapide et agile. 

<a href="https://gethomepage.dev/v0.7.3/">Homepage</a> est un tableau de bord **moderne**, **rapide** et **sécurisé** (entièrement proxyfié). 

**Customisable** de A à Z,  proposé avec des **centaines de widgets** et traduits dans plus de **40 langues**, il répondra aux besoins de personnalisation des plus pointilleux d'entre vous.

Le tout étant **simple** à mettre en place avec la magie de **Docker** et **facilement configurable** au travers de fichiers **YAML**.






<InfoBox>YAML signifie « **YAML Ain't Markup Language**. ».<br/>
Il s'agit d'un format de sérialisation de données lisible par l'homme qui est un sur-ensemble de JSON. <br/>
Idéal pour les fichiers de configuration, facile à lire et à écrire.<br/> Il prend en charge les types de données complexes tels que les listes et les objets. <br/>
L'indentation y est importante, mais si vous utilisez déjà Docker Compose, alors vous utilisez déjà YAML.</InfoBox>

## Installation

Pour installer Homepage vous avez plusieurs choix :

- <Icon name="uim:docker" class='h-12 pb-3 inline' /> Docker et Docker Compose
- <Icon name="mdi:kubernetes" class='h-12 pb-3 inline' /> Kubernetes
- <Icon name="simple-icons:unraid" class='h-12 pb-3 inline' /> UNRAID
- <Icon name="fa-solid:file-code" class='h-12 pb-3 inline' />  Depuis les sources

Nous, nous l'installerons avec  **Docker Compose**.

### Docker Compose

Utilisez le contenu de ce fichier <LittleCode code='docker-compose.yml' lang="docker" theme="vitesse-dark"/>.

<CodeBox code={`
version: "3.3"
services:
    homepage:
        image: ghcr.io/gethomepage/homepage:latest
        container_name: homepage
        ports:
            - 3000:3000
        volumes:
            - /path/to/config:/app/config # Assurez-vous que le dossier existe. 
            - /path/to/images:/app/public/images # Dossier pour stocker les images et icons
            - /var/run/docker.sock:/var/run/docker.sock # Pour intégration de Docker
`} lang="docker" theme="vitesse-dark" header="docker-compose.yml"/>

Si vous ne modifiez pas le port d'accès, vous devriez pouvoir accéder à l'application depuis  <a href="https://localhost:3000">https://localhost:3000</a>.

<ImageBox  src={CleanInstall} alt="Capture d'écran de Homepage juste après son installation."  orientation="horizontal"/>

La page par défaut est assez minime, mais nous allons configurer tout ça.

## Configuration

Tel qu'indiqué plus haut, la configuration est très simple et se situe dans 8 fichiers :

  -  **bookmark.yaml** : pour ajouter des favoris.
  -  **docker.yaml** & **kubernetes.yaml** : pour configurer l'accès aux serveurs Docker & Kubernetes. 
  -  **services.yaml** : pour configurer des services. (app docker ou kubernetes)
  -  **settings.yaml** : pour configurer Homepage (langue, thème, fond d'écran...)
  -  **widgets.yaml** : pour configurer des widgets. (météo, barre de recherche, calendrier...)
  - <Icon name="ph:file-css-light" class='h-8 inline' /> **custom.css** et <Icon name="ph:file-js-light" class='h-8 inline' /> **custom.js** : Pour modifier plus profondément encore Homepage.



### <Icon name="vscode-icons:file-type-yaml" class='h-12 pb-2 inline' /> docker.yaml

Nous allons tout d'abord **connecter** Homepage à notre **serveur Docker**.

### <Icon name="vscode-icons:file-type-yaml" class='h-12 pb-2 inline' /> services.yaml

Configurons maintenant quelques services, qui sont en fait d'**autres applications** qui tournent sur le même serveur Docker. 

<CodeBox code={`
- Vie courante:
    - Vikunja:
        icon: vikunja
        href: http://localhost:8085/
        description: To Do Liste
        server: mon-docker
        container: vikunja-frontend-1
- IT:
    - IT Tools:
        icon: it-tools.svg
        href: http://localhost:8081/
        description: Caisse à outils.
        server: mon-docker
        container: it-tools    
- Fichiers:
    - Zipline:
        icon: zipline-light.png
        href: http://localhost:8083/
        description: Pour gérer les fichiers.
        server: mon-docker
        container: zipline-zipline-1  
    - Hedgedoc:
        icon: synology-text-editor.png
        href: "http://localhost:8084/"
        description: Editeur de Markdown.
        server: mon-docker
        container: hedgedoc-app-1
- Outils:
    - Excalidraw: 
        icon: excalidraw-light.png
        href: http://localhost:8082/
        description: Pour dessiner des diagrammes.
        server: mon-docker
        container: priceless_grothendieck
`} lang="yaml" theme="vitesse-dark" header="services.yaml"/>

Deux lignes sont à noter : 

- <LittleCode code='server: mon-docker' lang="yaml" theme="vitesse-dark"/> : c'est le nom donné dans le fichier <LittleCode code='docker.yaml' lang="bash" theme="vitesse-dark"/>.
- <LittleCode code='container: XXX' lang="yaml" theme="vitesse-dark"/> : c'est le nom du container de l'application sur votre serveur Docker.

C'est grâce à ces deux lignes, couplé au fichier <LittleCode code='docker.yaml' lang="bash" theme="vitesse-dark"/> qu'Homepage peut vérifier de la disponibilité d'un service.
