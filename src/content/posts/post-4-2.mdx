## Qu'allons-nous faire ? 

Dans cette seconde partie, nous utiliserons **l'installateur** d'Astro pour **démarrer un projet** fourni avec des **fichiers d'exemple**.

Ces fichiers seront notre base pour mieux comprendre Astro. 


## Prérequis

- **Node.js** - v18.14.1 ou plus.
- Un éditeur de texte (<a href='/posts/cursor'>Cursor</a> 🥰).
- Un accès au **terminal**.

Que notons-nous ce coup-ci ? 

- Et bien tout d'abord que les données sont récupérées par des **constantes** dans la partie serveur : <LittleCode code='const { href, title, body } = Astro.props;' lang="astro" theme="vitesse-dark"/>  puis utilisé sous la forme <LittleCode code='{nomvariable}' lang="astro" theme="vitesse-dark"/> dans le html. 
- Que ces variables peuvent être utilisées comme **texte d'une balise h2** ou comme **URL d'un attribut href**.
- Enfin qu'on utilise  des **variables**  dans le CSS (Exemple : <LittleCode code='background-image: var(--accent-gradient);' lang="less" theme="vitesse-dark"/>). <br/>
Variables qui sont initialisées dans le CSS de **index.astro**, prouvant, par la même occasion la portée amplifiée de celui-ci grâce à <LittleCode code='<style is:global>' lang="astro" theme="vitesse-dark"/>.  

<InfoBigBox>
Notez que les constantes sont en fait incorporés comme **chaînes de caractères** au sein de votre page. **Impossible** donc de passer un **objet** ou une **fonction** dans votre page de cette manière.
<CodeBox code={`---
function handleClick () {
    console.log("clique clique clique!");
}
---
<!-- ❌ Ca ne fonctionne pas ❌ -->
<button onClick={handleClick}>Rien n'arrive quand vous me cliquez dessus !</button>
`} lang="astro" theme="vitesse-dark" header="A-NE-PAS-FAIRE"/>

Faites plutôt ceci : 

<CodeBox code={`---
---
<button id="button">Le clique qui fonctionne.</button>
<script>
  function handleClick () {
    console.log("Boutton cliqué !");
  }
  document.getElementById("button").addEventListener("click", handleClick);
</script>
`} lang="astro" theme="vitesse-dark" header="A-FAIRE"/>
</InfoBigBox>
